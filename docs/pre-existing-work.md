# Imported work

## Profile character assets (MakeHuman, CC0)

`Assets/HypaStories/Resources/HypaAvatar` is generated by `tools/avatar/build_avatar.py` from third-party CC0 assets:

- MakeHuman base mesh, targets (face and body shape), and the `mixamo_unity` rig and weights, as bundled with MPFB 2.0.18.
- From the MakeHuman CC0 system asset pack (`makehuman_system_assets_cc0.zip`): skins `young_caucasian_female`,
  `young_asian_female`, `young_african_female`; eyes `high-poly` and the brown eye material; `eyelashes01`; `eyebrow001`; hair `afro01`,
  `short01`, `short02`, `bob01`, `ponytail01`, `long01`; clothes `male_casualsuit01`, `03`, `05`, `06`, `female_elegantsuit01`,
  `female_sportsuit01`; `shoes01`.

The new work is the selection, the slider shape keys and blink, the clothing masks, texture processing (normalised and greyscale
variants for tinting), the thumbnails, and the runtime that uses them. MPFB and Blender (GPL-3.0) are build tools only and are
not included. See `THIRD_PARTY_NOTICES.md`.
